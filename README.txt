MATHS TRAINER PRO

GitHub Pages setup:
1. Create a new GitHub repository, e.g. maths-trainer.
2. Upload all files in this folder to the repository root.
3. Open Settings > Pages.
4. Choose Deploy from a branch, main, /root, then Save.
5. Open the GitHub Pages URL in Safari on iPhone.
6. Tap Share > Add to Home Screen > Add.
7. Open it once while online. It will then work offline.

Progress and history are stored locally on that device/browser.
